# SoundVault — Kho sound effect cho video Hiền Xa

**Bản khởi đầu: 16 file WAV có sẵn + 4 gói nguồn ngoài với tổng 330 âm thanh theo số lượng nhà cung cấp công bố.** 330 âm thanh ngoài chưa tải vào repo. Không cộng chúng vào số file đang có.

## Mở và dùng ngay
1. Vào thư mục [audio](audio), chọn file WAV rồi tải bằng nút Download raw file.
2. Kéo WAV vào CapCut, Premiere hoặc DaVinci Resolve; đặt trùng điểm hành động.
3. Muốn lấy cả kho: tại trang gốc repo chọn Code → Download ZIP, giải nén rồi mở SoundVault/audio.
4. Tra toàn bộ đường dẫn và thời lượng trong [catalog.json](catalog.json).

## Chọn tiếng theo cảnh
| File | Dùng cho |
|---|---|
| ui-click / digital-type / tick | Hiện chữ, gạch đầu dòng, đếm số |
| ui-pop | Bật chú thích, hiện giá |
| notification-ding / success-chime | Chốt thông tin, hoàn thành kiểm tra |
| error-buzz | Minh họa sai sót |
| transition-whoosh-short / transition-whoosh-long | Lia máy, đổi góc |
| impact-low / impact-tight | Nhấn câu hook, giá hoặc kết quả |
| tension-riser / transition-reverse | Chuẩn bị tiết lộ |
| comedy-slide-down / comedy-boing | Tình huống hài |
| reveal-sparkle | Lộ sản phẩm hoặc kết quả đẹp |

Đây là âm thanh **điện tử tổng hợp bằng công thức**, không phải âm thanh tách từ video, bản thu máy móc hay gói âm thanh của Kenney. WAV mono 22.05 kHz, 16 bit; phù hợp làm bản khởi đầu. Chưa nghe kiểm duyệt thẩm mỹ hoặc thử trong video thực tế.
